# 🍹 Cocktail Recommendation App - Mix'Mate 🍸

Mix'Mate est une app web 🕸️ développée en React ⚛️ qui permet aux utilisateurs de 🔎 rechercher, explorer 🌍 et découvrir 🎉 une variété de cocktails 🥂. L'app inclut des fonctionnalités comme un 🎠 carrousel interactif, des cocktails populaires 🌟, une recherche avancée 🧠, et une page de profil 👤 personnalisée.

## 🌟 Fonctionnalités principales

- **🔍 Recherche de cocktails** : Recherchez des cocktails par nom ou ingrédient 🥒.
- **🎠 Carrousel interactif** : Parcourez facilement une sélection de cocktails 🥂.
- **📂 Catégories** : Filtrez les cocktails par catégories (Classiques 🥃, Sans alcool 🧃, Exotiques 🍍, etc.).
- **🌟 Cocktails populaires** : Découvrez les boissons les plus appréciées 💕.
- **📅 Cocktail du jour** : Chaque jour, un cocktail unique est mis en avant 🌞.
- **👤 Page de profil** : Gérez vos préférences et consultez vos cocktails favoris 🌟.

## ⚙️ Prérequis

Avant de commencer, assurez-vous d'avoir les éléments suivants installés sur votre machine 🖥️ :

- **Node.js** (version 16 ou supérieure recommandée 🟢)
- **npm** ou **yarn** (inclus avec Node.js 📦)

## 🚀 Installation

1. Clonez le dépôt depuis GitHub 🐙 :
   ```bash
   git clone https://github.com/MaxMexico/Mix_Mate.git
   ```

2. Accédez au dossier du projet 📂 :
   ```bash
   cd Mix_Mate
   ```

3. Installez les dépendances 📦 :
   ```bash
   npm install
   ```

## 🏃‍♂️ Utilisation

1. Lancez le serveur de développement 🖥️ :
   ```bash
   npm start
   ```

2. Ouvrez votre navigateur 🌐 et accédez à :
   [http://localhost:3000](http://localhost:3000)

3. Explorez l'application et découvrez vos cocktails préférés 🥂 !

## 🔧 Scripts disponibles

Voici les scripts principaux que vous pouvez utiliser avec npm 🛠️ :

- **`npm start`** : Lance l'application en mode développement 🖥️.
- **`npm build`** : Compile l'application pour la production 🏗️.
- **`npm test`** : Exécute les tests 🧪.
- **`npm eject`** : Éjecte la configuration par défaut de Create React App ⚠️.

## 💻 Technologies utilisées

- **React ⚛️** : Framework JavaScript pour construire l'interface utilisateur.
- **Material-UI (MUI) 🎨** : Composants conformes à Material Design.
- **Swiper.js 🎠** : Carrousel interactif pour naviguer parmi les cocktails.
- **React Router 🚦** : Gestion des routes dans l'application.
