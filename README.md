# How to start the App on your phone 


## Step 1

Download Expo Go on your phone (in the App store)

Next, go to the root of the project (usualy <cd Mix_Mate_APP>)

## Step 2

Be ready to encounter some issues while lauching the app on your terminal. 

Install Yarn, npm Node.js, npm and Expo go 

You can check the prerequisite by entenring in the terminal 
'''
node -v
npm -v
java -version
'''

## Step 3

Link to the template : https://instamobile.io/app-templates/food-app-template/

To run the app, simply run

```yarn install && expo start```

And scan the QR code in the Expo client app. The QR Code will appear in your terminal, just scan it with your phone once Expo Go is installed

## Step 4 

If it doesn't work, send your terminal erros to ChatGPT he'll know what to do?
